🚀 Java Academy Projects

🎓 Java Academy – finanziata da Forma.Temp ed erogata da Bcsoft
Questo repository contiene esercizi, progetti e sperimentazioni pratiche in Java, inclusi Spring Boot e Hibernate, realizzati durante il percorso formativo della Java Academy.

📚 Contenuto del repository

Esercizi Base – variabili, operatori, condizioni e cicli

Programmazione Orientata agli Oggetti (OOP) – classi, oggetti, ereditarietà, polimorfismo e interfacce

Collezioni e Strutture Dati – Array, ArrayList, Set, Map

Gestione Eccezioni – eccezioni personalizzate

Progetti Pratici – mini-applicazioni per esercitazioni reali

Spring Boot – applicazioni web e RESTful API

Hibernate & JPA – persistenza dati e mapping oggetti-relazionale

⚡ Tecnologie e strumenti

Java 17+

Spring Boot 3.x

Hibernate / JPA

Eclipse IDE / IntelliJ IDEA

Maven / Gradle

Git & GitHub

🚀 Come eseguire i progetti

Clona il repository:

git clone https://github.com/tuo-username/java-academy.git

Apri il progetto nel tuo IDE preferito.

Per i progetti Java base, esegui la classe principale Main.java.

Per progetti Spring Boot:

mvn spring-boot:run

Per Hibernate, configura il database in application.properties.
